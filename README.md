# 📋 自动签到（Auto Check-in)

一个开箱即用的网页版自动签到工具。向日历/课程表添加课程，到点自动跳转签到链接，支持位置授权（可搭配浏览器定位拓展），无需后端、无需登录，数据保存在浏览器本地。

在线体验： https://auto-checkin-six.vercel.app/

---

## 主要功能

- 课程管理：添加 / 编辑 / 删除课程，支持课程名称、签到链接、星期、时间等字段  
- 自动签到：页面打开时在后台定时检测时间，匹配到设定时刻自动跳转签到链接  
- 倒计时提醒：清晰显示下一个签到的倒计时，便于提前准备  
- 位置授权：一键请求浏览器地理位置（部分签到页面需要）  
- 数据持久化：课程数据保存在浏览器 localStorage，关闭页面数据不丢失  
- 每周循环：按星期 + 时间自动循环，无需重复设置  
- 响应式：支持桌面、平板与手机浏览器

推荐组合：与可以修改浏览器位置定位的拓展配合使用（例如 MyLocationGuard：https://mylocationguard.org/）

## 使用说明（快速上手）

1. 打开页面，点击右下角 “+” 添加课程  
2. 填写：课程名称、签到链接、星期、上课时间（24 小时制）  
3. 如签到页面需要位置，点击顶部 “请求位置权限” 并允许浏览器定位  
4. 保持页面打开，到了设置时间会自动跳转到签到链接

注意：课程数据保存在浏览器 localStorage，清除浏览器数据或切换浏览器会导致数据丢失。

## 配置与隐私

- 所有数据均保存在本地，不会传输到服务器。  
- 若需模拟位置，请使用浏览器拓展（如 MyLocationGuard）或开发者工具的地理位置模拟功能。  
- 若要长期运行自动签到，建议使用始终保持打开的设备或部署在支持前端常驻的环境（例如持续运行的浏览器实例）。

## 常见问题（FAQ）

Q: 浏览器关闭后还能自动签到吗？
A: 不能。当前实现依赖页面在前端持续运行，关闭或刷新页面会中断调度。

Q: 是否支持导入/导出课程？
A: 当前版本未提供导入/导出功能；如需我可以帮你添加 CSV/JSON 导入导出功能。

Q: 数据丢失如何恢复？
A: 如果未手动备份且 localStorage 被清除，则无法恢复。建议增加导出功能以防止数据丢失。
